# 标题与基础事实来源政策

## 目标

标题、播出日期、改编状态和漫画 File 映射必须按字段审核，不能因为记录已有目录标题就视为全部基础事实完成。

## 来源分级

- `primary` / `official`：可直接支持官方作品信息；
- `reference-wiki`：可用于目录、标题和关系交叉核对，但重要冲突需要第二来源；
- `secondary-reference`：用于补充或交叉核对，不单独支撑深度剧透；
- `community-dataset`：只作为目录底稿，不直接支撑审核剧情字段。

## 标题接受规则

1. 保留 `ja`、`zhHans`、`zhHant`、`en` 和 `aliases` 的来源差异。
2. 没有可靠简体来源时，`zhHans` 保持 `null`，不能用手写繁简字典批量转换。
3. 一个标题候选至少带一个已登记来源；涉及译名冲突时尽量带两个来源。
4. 候选记录先进入 `data/candidates/episodes.json`，审核后才应用到规范化数据。
5. 批次报告必须区分候选数量、接受数量和实际字段变化数量。
6. 不因为标题补齐就把动画记录从 `catalog` 自动升级为 `reviewed`。

## 阻塞规则

网页无法访问、正文不完整、来源只给搜索摘要或译名冲突无法判定时，记录为 `blocked`，保留缺口，不猜测填充。
